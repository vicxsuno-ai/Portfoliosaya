## 🚀 Quick Start

### View the Website
Simply open `index.html` in your browser to view the portfolio.

### Deploy to GitHub Pages
1. Go to your repository settings
2. Under "Pages" section, select `main` (or your branch) as source
3. Save and wait for deployment
4. Your site will be available at `https://vicxsuno-ai.github.io/Portfoliosaya/`

### Local Development
```bash
# Clone the repository
git clone https://github.com/vicxsuno-ai/Portfoliosaya.git

# Navigate to the directory
cd Portfoliosaya

# Open with live server (if you have it installed)
# Or simply open index.html in your browser
```

## 🔧 Customization

### Change Colors
Edit the CSS variables in `styles.css`:
```css

    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... other colors */
}
```

### Modify Animations
